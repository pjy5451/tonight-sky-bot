# tonight-sky-bot

사용자가 고른 지역 기준으로 매일 저녁 ISS 통과 시각, 밝은 행성, 달, 유성우 소식을 보내는 텔레그램 봇입니다.

## 개발 환경

Python 3.11 이상이 필요합니다.

```bash
./bootstrap.sh
```

부트스트랩 스크립트는 가상환경을 만들고 개발 의존성을 설치한 뒤 테스트를 실행합니다.

## 테스트

```bash
python -m pytest
```

## 환경 변수

실제 비밀값은 `.env`에만 둡니다. 텔레그램 봇 토큰은 다음 이름으로 설정합니다.

```bash
SKY_BOT_TOKEN=
```
